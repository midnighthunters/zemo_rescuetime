# No Markdown Summary Files

Do not create markdown (.md) files to document changes, summaries, or explanations unless explicitly requested by the user.

## Rules

- Never create files like CHANGES.md, SUMMARY.md, TODO.md, FIXES.md, etc.
- Provide summaries and explanations directly in chat responses
- Only create markdown files when the user specifically asks for documentation
- Focus on code changes, not documentation artifacts
